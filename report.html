Going Online — step by step

Phase 1 · Local setup Done

  1. Git installed on this machine
  2. Project committed locally (git init, git add ., git commit), branch renamed to main

Phase 2 · Deploy the backend (Google Sheets) Your turn

  1. Open sheets.google.com → create a new blank spreadsheet (name it e.g. "Cashbook Data")
  2. Menu: Extensions → Apps Script
  3. Delete the placeholder code, paste the full contents of google-apps-script/Code.gs from this project
  4. Change the line var SECRET = 'CHANGE_ME_TO_A_RANDOM_SECRET'; to your own random string (e.g. cb_9f2k...) — keep it, you'll need it later
  5. Save (Ctrl+S) → click Deploy → New deployment
  6. Click the gear icon → select type Web app
  7. Execute as: Me · Who has access: Anyone → click Deploy
  8. Google will warn "Google hasn't verified this app" — click Advanced → Go to project (unsafe) → Allow (this is your own script, safe to allow)
  9. Copy the Web app URL shown (ends in /exec) — you'll paste this into the app's Settings

Phase 3 · Push to GitHub Your turn

  1. Go to github.com/new → Repository name: cashbook → do not add a README/gitignore → Create repository
  2. In a terminal, inside the A:\Cashbook folder, run: 
    git remote add origin https://github.com/<your-username>/cashbook.git
git push -u origin main
  3. A browser window will open asking you to log in to GitHub — log in to authorize the push

Phase 4 · Turn on GitHub Pages Your turn

  1. On the GitHub repo page → Settings → Pages
  2. Under "Build and deployment", set Source to GitHub Actions
  3. Go to the Actions tab — a workflow run starts automatically (~1-2 min)
  4. Once it's green, your site is live at https://<your-username>.github.io/cashbook/

Phase 5 · Connect the app Your turn

  1. Open your live site (the github.io link above) — it opens on the Settings screen since it's not connected yet
  2. Under "Data Source (Google Sheets)", paste the Web app URL and SECRET from Phase 2
  3. Tap Save & Test Connection — once it shows "Connected", the app is fully online and usable from any device/browser, no laptop required
