Going Online — steps left (your side)

  1. Deploy the backend: open sheets.google.com → new blank sheet → Extensions → Apps Script → paste google-apps-script/Code.gs from this project → change the SECRET value to your own random string → Deploy → New deployment → Web app → Execute as "Me" → Who has access "Anyone" → Deploy → approve the permission prompt (Advanced → Go to project) → copy the /exec URL.
  2. Install Git (not present on this machine yet) from git-scm.com.
  3. Push to GitHub: create a new repo named cashbook on GitHub → in this project folder run git init, git add ., git commit -m "Cashbook v1", git remote add origin <your repo URL>, git push -u origin main.
  4. Enable Pages: on the GitHub repo → Settings → Pages → Source: "GitHub Actions". The included workflow builds and deploys automatically on every push.
  5. Connect the app: open the deployed site → Settings → Data Source (Google Sheets) → paste the Web App URL and your SECRET → Save & Test Connection.

Ask Claude for the exact commands or Apps Script code any time — everything above is already written, just needs your Google/GitHub accounts to deploy.
